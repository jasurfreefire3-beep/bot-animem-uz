# Animem — Anime Platform & Telegram Bot

Animem — O'zbekistondagi zamonaviy anime platformasi hamda ilg'or Telegram bot integratsiyasi.

## Imkoniyatlar
- 🎬 **Full HD Video Player & Telegram Bot Stream**
- 🎟️ **Animem Pass (VIP)** obuna tizimi va cheklovlarsiz yuklab olish
- ❤️ **Sevimlilar (Favorites)** tizimi
- ⭐ **1–10 ballik Baholash (Rating)** mexanizmi
- 🔍 **Tezkor Inline Qidiruv** va filtrlash
- 📊 **PostgreSQL & In-Memory Database** bilan to'liq ma'lumotlar saqlanishi

## Ishga tushirish
```bash
# O'rnatish
npm install

# Ishga tushirish (Dev)
npm run dev

# Production Build
npm run build
npm start
```
